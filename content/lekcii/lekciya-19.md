## 3.4.2.5 Параметры шаблона, не являющиеся типами

> [!quote] Документация и стандарт по теме
> - Параметры шаблона (в том числе не являющиеся типами): https://cppreference.com/cpp/language/template_parameters
> - Стандарт: https://eel.is/c++draft/temp.param

В качестве аргументов шаблонов могут выступать также константы времени компиляции. Соответствующие параметры называют параметрами шаблона, не являющимися типами (non-type template parameters).

> [!abstract] Параметр шаблона, не являющийся типом (non-type template parameter)
> параметр шаблона, который заменяется не типом данных, а конкретным значением — константой времени компиляции.

Знакомый пример — `std::array<int, 5>`: размер массива задаётся параметром шаблона, не являющимся типом (см. 3.2 «Пользовательские типы данных и введение в STL»). Параметр, не являющийся типом, как и параметр-тип, компилятор умеет выводить из аргумента функции: в Примере 3.22 (см. 3.4.2.6) размер `N` массива `std::array<T, N>` выводится при вызове.

> [!example] Пример 3.20 — Факториал на параметре, не являющемся типом
> ```cpp
> #include <iostream>
>
> template<int Value>
> int getFactorial()
> {
>     return Value * getFactorial<Value - 1>();
> }
>
> template<>
> int getFactorial<1>()
> {
>     return 1;
> }
>
> int main()
> {
>     constexpr int RESULT = getFactorial<4>();
>     std::cout << RESULT << '\n';
>     return 0;
> }
> ```

> [!example] Пример — Указатель на функцию
> Написать шаблон функции `applyTwice`, который дважды применяет к целому числу `value` функцию, заданную параметром шаблона — указателем на функцию (см. [[lekciya-20#3.3.5 Указатели на функции|3.3.5 Указатели на функции]]). Проверить его на функции `square`, возводящей число в квадрат.
> ```cpp

> {

> }
>

> {
>     return Function(Function(value));
> }
>
> // applyTwice<square>(2) вернёт 16
> ```

> [!example] Пример — Указатель на объект со статической длительностью хранения
> Написать шаблон функции `isBelowLimit`, который проверяет, что целое число `value` меньше верхнего предела. Предел хранится в константе `MAX_SCORE` и передаётся через параметр шаблона — указатель на объект.
> ```cpp
> constexpr int MAX_SCORE = 100;
>
> template<const int* Limit>
> bool isBelowLimit(int value)
> {
>     return value < *Limit;
> }
>
> // isBelowLimit<&MAX_SCORE>(2) вернёт true
> ```

> [!example] Пример — Ссылка на объект со статической длительностью хранения
> Написать шаблон функции `isAboveLimit`, который проверяет, что целое число `value` больше нижнего предела. Предел хранится в константе `MIN_SCORE` и передаётся через параметр шаблона — ссылку на объект.
> ```cpp

>
> template<const int& Limit>
> bool isAboveLimit(int value)
> {
>     return value > Limit;
> }
>
> // isAboveLimit<MIN_SCORE>(2) вернёт true
> ```

> [!example] Пример — Указатель на член класса
> Написать шаблон функции `getCoordinate`, который возвращает координату точки `Point`. Какую координату вернуть — `x` или `y`, — задаётся параметром шаблона — указателем на член структуры.

## 3.4.2.6 Перегрузка шаблонов функций

> [!quote] Документация и стандарт по теме
> - Шаблон функции (раздел о перегрузке): https://cppreference.com/cpp/language/function_template
> - Стандарт, перегрузка шаблонов функций и частичное упорядочивание: https://eel.is/c++draft/temp.func.order

Шаблоны функций можно перегружать (function template overloading) — друг с другом и с обычными функциями.

> [!abstract] Перегрузка шаблонов функций (function template overloading)
> объявление в одной области видимости нескольких шаблонов функций с одним именем и разными сигнатурами либо шаблона и обычной функции с одним именем; нужный вариант компилятор выбирает для каждого вызова при разрешении перегрузки.

Экземпляры шаблонов участвуют в разрешении перегрузки наравне с обычными функциями (см. [[lekciya-17#3.4.1 Перегрузка функций|3.4.1 Перегрузка функций]]), и к общим правилам добавляются два:

- если обычная функция и экземпляр шаблона подходят одинаково хорошо, выбирается обычная функция;
- если одинаково хорошо подходят экземпляры нескольких шаблонов, выбирается более специализированный шаблон — тот, который принимает более узкий набор типов: шаблон с параметром `T*` специализированнее шаблона с параметром `T`.

При выводе `T` подбирается под тип аргумента, поэтому экземпляр шаблона обычно совпадает с аргументом точно и выигрывает у обычной функции, которой нужно продвижение или преобразование.

> [!example] Пример 3.21 — Выбор между шаблонами и обычной функцией
> ```cpp
> #include <iostream>
>
> template<typename T>
> void show(T value)
> {
>     std::cout << "шаблон: " << value << '\n';
> }
>
> template<typename T>
> void show(T* pointer)
> {
>     std::cout << "шаблон для указателя: " << *pointer << '\n';
> }
>
> void show(int value)
> {
>     // TODO: окончание примера на фото не попало
> ```

<!-- TODO: разбор примера 3.21 на фото не попал -->

> [!warning] Ловушка: специализация не участвует в перегрузке
> Явная специализация (`template<> void foo<char>(char)`) — не отдельная перегрузка, а другое тело для уже выбранного шаблона: сначала разрешение перегрузки выбирает шаблон, и только затем используется его специализация. Если нужно особое поведение для одного типа, обычно проще написать обычную функцию-перегрузку.

Перегрузкой можно задать особое поведение и сразу для целого семейства типов — например, для всех массивов `std::array` (см. 3.2 «Пользовательские типы данных и введение в STL»), любого типа элементов и любого размера. Тип элементов `T` и размер `N` компилятор выводит из аргумента функции: размер — параметр шаблона, не являющийся типом (см. 3.4.2.5).

## 3.4.2.8 Возвращаемый тип `decltype(auto)`

> [!quote] Документация и стандарт по теме
> - Спецификатор `decltype(auto)` и вывод возвращаемого типа: https://cppreference.com/cpp/language/function#Return_type_deduction
> - Стандарт, вывод возвращаемого типа: https://eel.is/c++draft/dcl.spec.auto

Тип результата шаблона функции часто зависит от параметров шаблона, и записать его заранее трудно. Начиная с C++14 возвращаемый тип можно поручить вывести компилятору (см. 3.3 доп. «auto, decltype и decltype(auto)»):

- `auto` выводит тип по правилам для переменных `auto`: ссылочность и верхнеуровневый `const` отбрасываются, функция возвращает копию;
- `decltype(auto)` выводит тип точно — как `decltype` от выражения в `return`: если выражение даёт ссылку, функция возвращает ссылку.

> [!example] Пример — Вывод возвращаемого типа с `auto`
> Написать функцию `getSum`, которая складывает значения типов `int` и `double`, не указывая возвращаемый тип явно.
> ```cpp
> #include <iostream>
>
> auto getSum(int a, double b)
> {
>     return a + b;
> }
>
> int main()
> {
>     std::cout << getSum(1, 0.5) << '\n'; // 1.5
>     return 0;
> }
> ```
> Выражение `a + b` имеет тип `double`, поэтому функция возвращает `double`.

На доске — та же функция в виде шаблона:

```cpp
template<typename T, typename S>
auto getSum(T a, S b) { /* … */ }
```

Вывод возвращаемого типа накладывает три ограничения:

- все `return` должны давать один тип: `return 1;` и `r…` <!-- TODO: продолжение пункта на фото обрезано -->
- <!-- TODO: начало второго пункта на фото не попало --> …неизвестен. Шаблоны это ограничение не затрудняет: их определение и так видно в месте использования (см. 3.4.2.7 Размещение шаблонов в заголовочных файлах);
- рекурсивный вызов возможен только после первого `return`: к этому моменту тип уже выведен.

> [!example] Пример 3.24 — `auto` и `decltype(auto)` в возвращаемом типе

## 3.4.2.9 Шаблон псевдонима

> [!info] Свойства заметки
> Тип: параграф учебника · статус: черновик · дата обновления: 31.10.2026 · предпосылки: 3.4.2.8 Возвращаемый тип `decltype(auto)`.

> [!quote] Документация и стандарт по теме
> - Шаблон псевдонима: https://cppreference.com/cpp/language/type_alias
> - Стандарт, шаблоны псевдонимов: https://eel.is/c++draft/temp.alias

Псевдоним типа `using имя = тип;` (см. [[lekciya-16#1.6.3 Ключевое слово using|1.6.3 Ключевое слово using]]) тоже бывает шаблоном. **Шаблон псевдонима** (alias template) задаёт семейство псевдонимов, зависящих от параметра шаблона: подставив аргумент шаблона, получают псевдоним конкретного типа.

```cpp
template<typename T>
using Matrix = std::vector<std::vector<T>>; // шаблон псевдонима

Matrix<int> grid{{0, 1}, {1, 2}}; // то же, что std::vector<std::vector<int>>
Matrix<double> weights(2, std::vector<double>(2, 0.5)); // матрица 2×2 из значений 0.5
```

Как и обычный псевдоним, шаблон псевдонима новых типов не создаёт: `Matrix<int>` и `std::vector<std::vector<int>>` — один и тот же тип, и значения передаются между ними без преобразования.

До появления `using` псевдонимы типов объявляли только с `typedef`.

> [!abstract] Спецификатор `typedef`
> спецификатор объявления, унаследованный из языка C: имя, объявленное с `typedef`, обозначает не переменную, а псевдоним типа.

Запись строится так: берут объявление переменной и ставят перед ним `typedef`. Имя остаётся на том же месте, но становится псевдонимом типа, который имела бы переменная:

```cpp
unsigned long long total;          // переменная total
typedef unsigned long long Total;  // псевдоним типа Total

int pair[2];          // массив pair
typedef int Pair[2];  // псевдоним типа «массив из двух int»
```

Как и `using`, `typedef` новых типов не создаёт: `Total` и `unsigned long long` — один и тот же тип, поэтому функции `void f(Total)` и `void f(unsigned long long)` — это одна функция, а не перегрузка.

Одно объявление `typedef` может ввести несколько имён, и знак `*` относится только к тому имени, перед которым стоит: в записи `typedef int* IntPointer, Number;` имя `IntPointer` обозначает `int*`, а `Number` — `int`.

Шаблон псевдонима можно объявить только с `using`: запись `template<typename T> typedef …` — ошибка (`a typedef cannot be a template`).

Правило T.43 из C++ Core Guidelines [7] рекомендует объявлять псевдонимы с `using`, а не с `typedef`, и приводит три причины:

- **читаемость**: с `using` новое имя стоит первым, а не внутри объявления;
- **общность**: `using` может быть шаблоном, а `typedef` — нет;
- **единообразие**: запись `using имя = …` похожа на объявление `auto имя = …`.

> [!example] Пример — Псевдонимы с `typedef` и с `using`
> Объявить псевдоним указателя на функцию и шаблон такого псевдонима.
> ```cpp
> typedef int (*OldUnaryFunction)(int); // имя стоит внутри объявления
> using UnaryFunction = int (*)(int);   // имя стоит первым
>
> template<typename T>
> using Callback = void (*)(T); // шаблон псевдонима
>
> template<typename T>
> struct OldCallback
> {

### Валидация аргументов шаблона — концепты (с C++20)

При описании шаблона функции

```cpp
template<typename T>
T max(T a, T b);
```

неминуемо возникает вопрос: «Как проверяется корректность типа, который подставляется в шаблон?»

В шаблоне тип как-то используется. Например, что будет, если передать в качестве аргумента шаблона `T` тип, не поддерживающий оператор сравнения `<`?

До C++20 такую ошибку компилятор обнаруживал только при подстановке, когда некомпилирующаяся конструкция уже полностью порождена, и сообщал о ней внутри тела шаблона, а не в месте вызова (см. Пример 3.31 ниже). Это была одна из главных проблем шаблонов и, в целом, одна из главных проблем языка C++.

Проблему с валидацией решали по-разному. Использовали правило SFINAE (substitution failure is not an error — «неудачная подстановка не является ошибкой») и основанный на нём шаблон `std::enable_if`, проверяли требования объявлением `static_assert` (см. «Проверочные утверждения assert и static_assert»), придумывали стили комментариев, в которых текстом описывались бы требования к аргументам <!-- TODO: продолжение на фото обрезано -->

> [!example] Пример 3.25 — Ограничение стандартным концептом `std::totally_ordered`
> ```cpp
> #include <concepts>
> #include <iostream>
>
> template<typename T>
>     requires std::totally_ordered<T>
> T max(T a, T b)
> {
>     return (a < b) ? b : a;
> }
>
> int main()
> {
>     std::cout << max(3, 7) << ' ' << max(2.5, 1.5) << '\n'; // 7 2.5
>     return 0;
> }
> ```
> `std::totally_ordered<T>` — стандартный концепт библиотеки из `<concepts>`, который требует, чтобы тип поддерживал все операции сравнения: `<`, `<=`, `>`, `>=`, `==`, `!=`.

> [!example] Пример 3.26 — Собственный концепт `LessThanComparable`
> ```cpp
> #include <concepts>
> #include <iostream>
>
> template<typename T>
> concept LessThanComparable = requires(T a, T b) {
>     { a < b } -> std::convertible_to<bool>;
> };
>
> template<LessThanComparable T>
> T max(T a, T b)
> {
>     return (a < b) ? b : a;
> }
>
> int main()
> {
>     std::cout << max(3, 7) << ' ' << max(2.5, 1.5) << '\n'; // 7 2.5
>     return 0;
> }
> ```

### Ограничение, концепт, requires

> [!abstract] Ограничение (constraint)
> логическое условие на параметры шаблона, которое компилятор проверяет при подстановке аргументов шаблона; если условие не выполнено, шаблон исключается из числа кандидатов при разрешении перегрузки.

> [!abstract] Концепт (concept)
> именованное ограничение — шаблон, объявленный ключевым словом `concept`; запись `Концепт<T>` — константное выражение типа `bool`, истинное, если тип `T` удовлетворяет требованиям концепта.

> [!abstract] requires-условие (requires clause)
> часть объявления шаблона вида `requires ограничение`, которая задаёт ограничение для его параметров.

> [!abstract] requires-выражение (requires expression)
> выражение вида `requires (параметры) { требования }` (параметры можно опустить: `requires { требования }`), которое истинно, если все перечисленные требования к типам и выражениям выполнимы; сами выражения при этом не вычисляются.

### Сокращённая запись шаблона функции

С C++20 параметр функции можно объявить с типом `auto`. Такая функция — шаблон функции, записанный сокращённо: каждый параметр `auto` вводит собственный параметр шаблона. Запись

```cpp
void printTwice(auto value)
```

равносильна

```cpp
template<typename T>
void printTwice(T value)
```

> [!example] Пример 3.28 — Параметры `auto`
> ```cpp
> #include <iostream>
>
> void printTwice(auto value)
> {
>     std::cout << value << ' ' << value << '\n';
> }
>
> auto sum(auto a, auto b)
> {
>     return a + b;
> }
>
> int main()
> {
>     printTwice(5);
>     printTwice("hi");
>     std::cout << sum(1, 2.5) << '\n'; // a - int, b - double: 3.5
>     return 0;
> }
> ```
> Вывод программы:
> ```
> 5 5
> hi hi
> 3.5
> ```
