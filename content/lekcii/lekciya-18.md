## 3.4.2.2 Параметры и аргументы шаблона

> [!abstract] Параметр шаблона (template parameter)
> имя в списке параметров шаблона, вместо которого при использовании шаблона подставляется аргумент шаблона.

> [!abstract] Аргумент шаблона (template argument)
> тип, значение или шаблон, подставляемый в параметр шаблона.

Использование шаблона выглядит так: `findMax<int>(a, b)`. В угловых скобках передаются аргументы шаблона.

В данном случае в качестве аргумента шаблона `T` передаётся тип `int`. После подстановки компилятор создаст «под капотом» конкретную функцию из обобщённого кода: так, в примере 3.17 из шаблона `swap` создаются функции `swap<int>` и `swap<double>` (см. [[lekciya-17#3.4.2 Шаблоны функций|3.4.2.1 Объявление шаблона]]). То, что вызывается по записи `findMax<int>(a, b)`, для компилятора выглядит так (это условная запись: в программе так написать нельзя):

### Терминология

> [!abstract] Экземпляр шаблона функции, специализация шаблона функции (function template specialization)
> конкретная функция, которую компилятор порождает из шаблона функции, подставив в него аргументы шаблона.

Шаблон сам по себе не превращается в реальный код: для компилятора это рецепт, правило «генерации» кода функции. Экземпляр порождается, только когда шаблон используется с конкретными аргументами. Поэтому для разных аргументов шаблона на этапе компиляции будут порождаться разные экземпляры, а для неиспользованного шаблона — ни одного.

В литературе экземпляр иногда называют «шаблонной функцией». Этого выражения лучше избегать: его легко принять за сам шаблон функции.

> [!abstract] Обобщённое программирование (generic programming)
> парадигма программирования, заключающаяся в таком описании данных и алгоритмов, которое можно применять к различным типам данных, не меняя само это описание.

### Виды параметров шаблона

Параметры шаблона бывают трёх видов:

- **параметр-тип** объявляется ключевым словом `typename` или `class` (см. 3.4.2.1 Объявление шаблона); аргументом служит тип: фундаментальный (`int`, `double`), указатель, `std::string`, пользовательская структура. С C++20 вместо `typename` можно записать концепт, и тогда тип обязан удовлетворять его требованиям (см. [[lekciya-19#3.4.3 Концепты|3.4.3 Концепты]]);
- **параметр, не являющийся типом** (non-type template parameter) объявляется типом значения, например `std::size_t N`; аргументом служит константа времени компиляции (см. [[lekciya-19#3.4.2.5 Параметры шаблона, не являющиеся типами|3.4.2.5]]);
- **шаблонный параметр шаблона** (template template parameter) объявляется как `template<typename> typename Container`; аргументом служит сам шаблон класса, например `std::vector` без угловых скобок. Шаблоны классов разбираются в теме 5.3.

> [!example] Пример — Три вида параметров шаблона
> ```cpp
> #include <cstddef>
> #include <iostream>
> #include <string>
> #include <vector>
>
> template<typename T>
> void printValue(T value)
> {
>     std::cout << value << '\n';
> }
>
> template<std::size_t N>
> void printLine()
> {
>     std::cout << std::string(N, '-') << '\n';
> }
>
> template<template<typename> typename Container>
> void printSize()
> {
>     Container<int> values{1, 2, 3};
>     std::cout << values.size() << '\n';
> }
>
> int main()
> {
>     printValue(42);
>     printLine<5>();
>     printSize<std::vector>();
>     return 0;
> }
> ```

### Зависимые имена: `typename` и `class`

В заголовке шаблона слова `typename` и `class` равнозначны (см. 3.4.2.1 Объявление шаблона). Различие появляется, когда внутри шаблона нужен тип, вложенный в параметр шаблона, например тип элементов контейнера `Container::value_type`.

> [!abstract] Зависимое имя (dependent name)
> имя внутри шаблона, смысл которого зависит от параметра шаблона.

Читая шаблон, компилятор ещё не знает, какой тип подставят вместо `Container`, и по правилам языка считает `Container::value_type` не типом. Слово `typename` перед таким именем сообщает компилятору, что это тип:

> [!example] Пример — Шаблон, возвращающий элемент контейнера
> ```cpp
> #include <iostream>
> #include <string>
> #include <vector>
>
> template<typename Container>
> typename Container::value_type findLargest(const Container& values)
> {
>     typename Container::value_type largest = values[0];
>     for (const auto& value : values) {
>         if (value > largest) {
>             largest = value;
>         }
>     }
>     return largest;
> }
>
> int main()
> {
>     std::vector<int> numbers{3, 7, 5};
>     std::vector<std::string> words{"cat", "zebra", "dog"};
>     std::cout << findLargest(numbers) << '\n';
>     std::cout << findLargest(words) << '\n';
>     return 0;
> }
> ```

Заменить здесь `typename` на `class` нельзя:

```cpp
typename Container::value_type largest = values[0];   // верно
class Container::value_type largest = values[0];      // ошибка
```

Запись `class Имя` утверждает, что имя обозначает именно класс. У `std::vector` тип `value_type` — псевдоним, поэтому компилятор сообщает: `type alias 'value_type' cannot be referenced with the 'class' specifier`. В заголовке же `template<class Container>` слово `class` по-прежнему допустимо.

С C++20 в возвращаемом типе `typename` можно не писать: перед именем функции может стоять только тип. В объявлении локальной переменной `typename` обязательно: в теле функции запись может быть как объявлением, так и выражением, поэтому без `typename` компилятор считает вложенное имя не типом.

Наглядный случай — символ `*`, который обозначает и объявление указателя, и умножение. Запись вида `Container::value_type * x` меняет смысл в зависимости от того, чем окажется `value_type`:

> [!example] Пример — Одно вложенное имя: тип или значение
> ```cpp
> #include <iostream>
>
> struct Numbers
> {
>     using value_type = int;
> };
>
> struct Scale
> {
>     static constexpr int value_type = 5;
> };
>
> template<typename Container>
> void printThroughPointer(int number)
> {
>     typename Container::value_type* x = &number;
>
>     std::cout << *x << '\n';
> }
>
> template<typename Container>
> int multiply(int x)
> {
>     return Container::value_type * x;
> }
>
> int main()
> {
>     printThroughPointer<Numbers>(7);
>     std::cout << multiply<Scale>(2) << '\n';
>     return 0;
> }
> ```

### Пакет параметров

> [!abstract] Пакет параметров (parameter pack)
> параметр шаблона или функции, принимающий ноль или более аргументов.

Параметр любого из трёх видов можно сделать пакетом параметров, поставив многоточие: параметр `typename... Args` принимает любое число аргументов-типов, в том числе ни одного (см. 3.4.2 доп. «Шаблоны с переменным числом параметров»).

> [!example] Пример — Пакет параметров
> ```cpp
> #include <iostream>
>
> template<typename... Args>
> void printCount(const Args&... args)
> {
>     std::cout << sizeof...(args) << '\n';
> }
>
> int main()
> {
>     printCount();
>     printCount(42);
>     printCount(1, 2.5, 'x');
>     return 0;
> }
> ```
> Вывод программы:
> ```
> 0
> 1
> 3
> ```

Оператор `sizeof...` работает только с пакетами параметров. Для функции с многоточием `...` (см. [[lekciya-17#Многоточие: функции с переменным числом аргументов|3.4.1 Перегрузка функций]]) он неприменим: переменная `args` типа `std::va_list` — не пакет, и компилятор сообщает `'args' does not refer to the name of a parameter pack`. Обычный `sizeof(args)` вернёт размер самой переменной, а не число аргументов. Различие глубже синтаксиса:

| | Пакет параметров | Многоточие |
|---|---|---|
| Когда известно число аргументов | при компиляции: для каждого набора типов создаётся свой экземпляр | при компиляции функции неизвестно: одна функция на все вызовы |
| Известны ли типы аргументов | да | нет |
| Как узнать число аргументов | `sizeof...(args)` | только по договорённости: счётчик, строка формата, сторожевое значение |

### Параметры шаблона по умолчанию

Параметру шаблона, как и параметру функции, можно задать значение по умолчанию: `template<typename T = int>`.

> [!example] Пример — Тип по умолчанию, когда его нельзя вывести
> ```cpp
> #include <iostream>
>
> template<typename T, typename Result = double>
> Result average(T a, T b)
> {
>     return static_cast<Result>(a + b) / 2;
> }
>
> int main()
> {
>     std::cout << average(3, 4) << '\n';
>
>     std::cout << average<int, int>(3, 4) << '\n';
>
>     return 0;
> }
> ```
> Вывод программы:
> ```
> 3.5
> 3
> ```

Значение по умолчанию используется, если аргумент шаблона не указан и его нельзя вывести из аргументов функции. Так, `T` в `average` выводится из аргументов функции, а `Result` вывести не из чего: он встречается только в возвращаемом типе. Другое частое применение — настройка, которая обычно не нужна: вызывающий указывает её, только когда хочет изменить поведение. В примере ниже `std::less` и `std::greater` из заголовочного файла `<functional>` — стандартные средства сравнения: их объекты вызываются как функции и проверяют условия «меньше» и «больше»:

> [!example] Пример — Способ сравнения по умолчанию
> ```cpp
> #include <functional>
> #include <iostream>
>
> template<typename T, typename Compare = std::less<T>>
> T selectBest(T a, T b, Compare isBetter = Compare{})
> {
>     return isBetter(b, a) ? b : a;
> }
>
> int main()
> {
>     std::cout << selectBest(3, 7) << '\n';
>
>     std::cout << selectBest(3, 7, std::greater<int>{}) << '\n';
>
>     return 0;
> }
> ```

## 3.4.2.3 Вывод аргументов шаблона

<!-- TODO: начало параграфа на фото не попало -->

> [!example] Пример 3.18 — Вывод аргумента шаблона
> ```cpp
> #include <iostream>
>
> template<typename T>
> T findMax(T a, T b)
> {
>     return (a >= b ? a : b);
> }
>
> int main()
> {
>     const int a = 3;
>     const int b = 2;
>     const char c = 'b';
>     std::cout << findMax<int>(a, b) << '\n';
>
>     std::cout << findMax(a, b) << '\n';
>
>     std::cout << findMax<int>(a, c) << '\n';
>
>     return 0;
> }
> ```

Вызов `findMax(a, b)` корректен с точки зрения языка. Компилятор проанализирует типы переменных `a` и `b` и выполнит вывод аргумента шаблона `T`. Тип переменной `a` — `int`, тип переменной `b` — тоже `int`. Они передаются в шаблон функции `template<typename T> T findMax(T a, T b)`, в котором ожидается, что оба аргумента будут иметь одинаковый тип `T`. Так как типы `a` и `b` совпадают и нет других правил, ограничивающих параметр шаблона `T`, компилятор делает вывод, что записью `findMax(a, b)` ожидают применения экземпляра `findMax<int>(a, b)`.

> [!warning] Ловушка: конфликт при выводе аргумента шаблона
> Вызов `findMax(a, c)` из Примера 3.18 не скомпилируется. Типы переменных `a` и `c` не совпадают, и компилятор не может однозначно определить, какой тип надо передать в качестве аргумента `T`: у него есть вариант подставить тип `int` или тип `char`, и непонятно, какая из подстановок ожидается программистом. Сообщение clang++:
> ```
> error: no matching function for call to 'findMax'
> note: candidate template ignored: deduced conflicting types for parameter 'T' ('int' vs. 'char')
> ```
> g++ сообщает о том же: `deduced conflicting types for parameter 'T' ('int' and 'char')`.

Чтобы избавиться от этой проблемы, можно применить явную передачу типа в шаблон: `findMax<int>(a, c)`. Теперь экземпляр шаблона определён однозначно: `int findMax<int>(int, int)`. Значение переменной `c` в этом вызове приведётся к типу `int` — так же, как это произошло бы при вызове нешаблонной функции `int findMax(int, int)`.

## 3.4.2.4 Явная специализация шаблона функции

> [!quote] Документация и стандарт по теме
> - Явная специализация: https://cppreference.com/cpp/language/template_specialization
> - Стандарт: https://eel.is/c++draft/temp.expl.spec
> - Дополнительные примеры: статья на Хабре, radioprog.ru

Специализация позволяет описывать вариации шаблонов, которые надо выбирать при передаче в шаблон определённых заданных типов.

> [!abstract] Явная специализация шаблона функции (explicit specialization)
> отдельное определение шаблона функции для конкретных аргументов шаблона; объявляется с префиксом `template<>` и задаёт для этих аргументов особое поведение вместо общего.

Явную специализацию ещё называют полной: фиксируются все аргументы шаблона — они указаны явно или выведены из типов параметров функции.

```cpp
template<typename T>
void foo(T) {}

template<>
void foo<char>(char) {}

template<>
void foo(double) {}
```

Часть `template<>` сообщает компилятору, что это явная специализация.

> [!info] Почему специализация называется полной
> Полная специализация фиксирует все параметры шаблона, поэтому её результат — конкретная функция, а не шаблон, и список `template<>` пуст. Этим она отличается от частичной специализации, которая фиксирует только часть параметров, так что результат остаётся шаблоном:
> ```cpp
> template<typename T, typename U>
> void g(T, U) {}
>
> template<>
> void g<int, double>(int, double) {}   // полная специализация
>
> template<typename U>
> void g<int, U>(int, U) {}             // частичная — для функций недопустима
> ```
> Частичной специализации у шаблонов функций нет; она существует только для шаблонов классов и переменных. У шаблонов функций похожий результат даёт перегрузка: см. [[lekciya-19#3.4.2.6 Перегрузка шаблонов функций|3.4.2.6 Перегрузка шаблонов функций]].

> [!example] Пример 3.19 — Особое поведение для разных типов
> ```cpp
> #include <iostream>
>
> template<typename T>
> void print(T value)
> {
>     std::cout << "число: " << value << '\n';
> }
>
> // явная специализация: значения типа double выводятся в экспоненциальной записи
> template<>
> void print<double>(double value)
> {
>     std::cout << "число: " << std::scientific << value << '\n';
> }
>
> // явная специализация для char: символ и его код
> template<>
> void print<char>(char value)
> {
>     std::cout << "символ: " << value << ", код: " << static_cast<int>(value) << '\n';
> }
>
> template<>
> void print<const char*>(const char* value)
> {
>     std::cout << "строка: " << value << '\n';
> }
>
> int main()
> {
>     print(42);
>     print(1234.5);
>     print('A');
>     print("hello");
>     // TODO: окончание примера и вывод на фото не попали
> ```

> [!warning] Ловушка: специализация для `std::string` не срабатывает на строковом литерале
> Если в Примере 3.19 вместо специализации для `const char*` написать специализацию для `std::string`, программа скомпилируется без ошибок, но вызов `print("hello")` её не выберет:
> ```cpp
> template<>
> void print<std::string>(std::string value)
> {
>     std::cout << "строка: " << value << '\n';
> }
>
> print("hello");                 // общий шаблон
>
> print(std::string{"hello"});    // специализация
> print<std::string>("hello");    // специализация
> ```
> Литерал `"hello"` имеет тип `const char[6]`, поэтому выводится `T = const char*` (см. Пример 3.19), а не `std::string`. Преобразование `const char*` в `std::string` при выводе аргумента шаблона не рассматривается, и компилятор использует общий шаблон. Специализация срабатывает только тогда, когда `T` совпадает с её аргументом точно.
