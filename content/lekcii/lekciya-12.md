## 1.2.6 Инструкции циклов

Цикл — это любая многократно исполняемая последовательность инструкций.

Существует два вида циклов:

- цикл с известным числом шагов (например, сделать 10 раз) ~ `for`;
- цикл с неизвестным числом шагов (например, ползти вверх или ползти «пока не надоест») ~ <!-- TODO: окончание строки на фото обрезано; по смыслу — while / do-while -->

### 1.2.6.1 Цикл while

> [!abstract] Цикл `while` (while loop)
> инструкция цикла, которая повторно выполняет тело, пока значение условия равно `true`; условие проверяется перед каждой итерацией.
>
> ```
> while (условие)
>     инструкция
> ```

```cpp
int sum = 0;
int i = 1;
while (i <= 100) {
    sum += i++;
}
```

```cpp
int sum = 0;
int i = 1;
while (i <= 100) {
    sum += i;
    // TODO: продолжение второго варианта на фото обрезано (по смыслу: ++i;)
}
```

### 1.2.6.2 Цикл do-while

> [!abstract] Цикл `do-while` (do-while loop)
> инструкция цикла, которая повторно выполняет тело, пока значение условия равно `true`; условие проверяется после каждой итерации.
>
> ```
> do
>     инструкция
> while (условие);
> ```

Тело цикла в инструкции `do-while` всегда выполняется хотя бы один раз, даже если выражение всегда даёт `false`. Если в этом случае тело цикла не должно выполняться, то нужно использовать цикл `while` или `for`.

```cpp
int sum = 0;
int i = 1;
do
    sum += i++;
while (i <= 100);
```

#### Пример с циклом while и do-while

```cpp
// пример ввода числа из диапазона [1, 10] с циклом while
int k = 0; // наверняка неверное значение
while (k < 1 || k > 10) {
    std::cout << "Input number from the range [1,10]\n";
    std::cin >> k;
}

// тот же пример но с циклом do-while
int k; // обходимся без искусственной инициализации
do {
    std::cout << "Input number from the range [1,10]\n";
    std::cin >> k;
} while (k < 1 || k > 10);
```

### 1.2.6.3 Цикл for

> [!abstract] Цикл `for` (for loop)
> инструкция цикла, которая выполняет инициализацию, а затем повторяет тело и выражение итерации, пока значение условия равно `true`; условие проверяется перед каждой итерацией.
>
> ```
> for (инициализация; условие; выражение-итерации)
>     инструкция
> ```

Цикл `for` эквивалентен следующей записи с циклом `while`:

```
{
    инициализация;
    while (условие) {
        инструкция
        выражение-итерации;
    }
}
```

### 1.2.6.4 Цикл for, основанный на диапазоне (Range-based-for-loop, с C++11)

> [!abstract] Цикл `for` по диапазону (range-based for loop)
> инструкция цикла, которая по очереди связывает переменную из объявления с каждым элементом диапазона — контейнера или массива — и для каждого элемента выполняет тело.
>
> ```
> for (объявление-элемента : диапазон)                   // с C++11
>     инструкция
>
> for (инициализация; объявление-элемента : диапазон)    // с C++20
>     инструкция
> ```

Используется как более читаемый эквивалент традиционного цикла `for` при работе с контейнерами.

```cpp
std::vector<int> numbers = {0, 1, 2, 3, 4, 5};
// распечатать список элементов вектора
for (int current : numbers) {
    std::cout << current << ", ";
}
```

Эквивалентно:

```cpp
for (std::size_t i = 0; i < numbers.size(); ++i) {
    int current = numbers[i];
    std::cout << current << ", ";
}
```

Range-based for loop (цикл «на основе диапазона») — это конструкция, позволяющая итерироваться по диапазону элементов, предоставляемых контейнером (например, `std::vector`, `std::list`, `std::array`, `std::string`) или массивом. Он автоматизирует процесс извлечения элементов один за другим, предоставляя их в удобном формате.

```cpp
std::vector<int> numbers = {0, 1, 2, 3, 4, 5};

// Пример 1. Для удобства можно использовать auto для «вычисляемого» типа данных
for (auto item : numbers) { // доступ по значению, исходные данные не изменятся
    std::cout << item << ", ";
}

// Пример 2. Если данные в коллекции надо изменять, или с целью предотвратить
// копирование, которое срабатывает при передаче по значению, необходимо использовать
// передачу по ссылке
for (auto& item : numbers) { // доступ по ссылке
    ++item; // каждый элемент коллекции увеличится на 1
}

// Пример 3. С целью «защиты» от изменений при работе со ссылкой — используем
// константную ссылку; распечатать список элементов вектора (значения не изменятся)
for (const auto& item : numbers) { // доступ по константной ссылке
    // ++item; // Ошибка компиляции, т.к. пытаемся изменить константную переменную
    std::cout << item << ' '; // можно только обращаться к значению
}
```

## 1.2.7 Инструкции перехода (jump statements)

> [!quote] Документация и стандарт по теме
> **Документация:**
> - Инструкции перехода (обзор): <https://cppreference.com/cpp/language/statements#Jump_statements>
> - `break`: <https://cppreference.com/cpp/language/break>
> - `continue`: <https://cppreference.com/cpp/language/continue>
> - `return`: <https://cppreference.com/cpp/language/return>

>
> **Стандарт:**
> - Инструкции перехода: <https://eel.is/c++draft/stmt.jump>

> [!abstract] Инструкция перехода (jump statement)
> инструкция, безусловно передающая управление в другую точку программы.
>
> ```
> break;               // выход из цикла или switch, см. 1.2.5, 1.2.6
> continue;            // переход к следующей итерации, см. 1.2.6
> return выражение;    // завершение функции; выражение может отсутствовать
> return {список};     // return со списком инициализации: return {1, 2, 3};
> goto метка;          // переход на помеченную инструкцию, см. 1.2.2
> ```

Для всех инструкций перехода переход из цикла, из блока или назад за пределы инициализированной переменной с автоматической продолжительностью хранения влечёт за собой уничтожение объектов с автоматической продолжительностью хранения, которые находятся в области действия в точке, из которой был выполнен переход, но не в точке, в которую был выполнен переход.

Это значит, что когда используются `break`, `continue`, `goto` или `return` для выхода из блока кода (цикла, `if`, функции) или за пределы области видимости переменной, то все объекты, объявленные <!-- TODO: окончание абзаца на фото не попало -->

## 1.2.8 Инструкции объявления

<!-- TODO: начало параграфа (документация) на фото не попало -->

> [!abstract] Инструкция объявления (declaration statement)
> инструкция, которая вводит в блок один или несколько идентификаторов. Кроме имени и типа она задаёт сущности область видимости (scope) и связывание (linkage).
>
> ```
> тип имя;                          // без инициализатора
> тип имя инициализатор;            // = значение, {значение} или (значение)
> тип имя-1 инициализатор, имя-2;   // несколько имён в одной инструкции
> ```

> [!tip] Свойства объявлений
> - Каждый тип сущности объявляется по-разному.
> - Некоторые объявления могут происходить несколько раз для одной и той же сущности (например, несколько объявлений функции в разных заголовочных файлах).
> - Объявление не обязательно создаёт сущность — оно лишь говорит компилятору о её существовании.

```cpp
int x;          // объявление и определение переменной
extern int y;   // только объявление, определение где-то ещё
```

### Объявления и определения

Определение — это объявление, достаточное для использования сущности: оно создаёт сущность в памяти (выделяет память под переменную, предоставляет реализацию функции, задаёт структуру класса). Отсюда и несимметричность: объявлений у сущности может быть сколько угодно, определение — ровно одно.

**Правило одного определения** (One Definition Rule, ODR) — для каждой сущности (типа данных, переменной, функции, объекта, шаблона) в программе должно быть только одно определение. По-настоящему это правило начинает работать, когда программа собирается из нескольких файлов, поэтому разбирается оно в теме о многомодульных приложениях — см. 07 7.6 «Правило одного определения ODR».

### Инициализация переменных

Инициализация — это задание объекту начального значения в момент его создания (в отличие от присваивания, которое меняет значение уже существующего объекта).

Начальное значение может быть задано:

1. при объявлении, например, `int i = 3; Point p1{1, 2};`
2. при создании сущности с помощью операции `new`, например, `int* ptr = new int(7);`
3. при вызове функции — при передаче параметров функции, например, `setPoint(Point{5,6});`
4. при вызове функции — при возвращении ею значения, например, `Point copyPoint(int x, int y) { return { x, y }; }`

### Виды инициализации

Инициализатор, если он есть, определяет, какой из видов инициализации применяется. Каждый разобран в отдельном параграфе:

### 1.2.8.1 Инициализация по умолчанию

> [!quote] Документация и стандарт по теме
> **Документация:**
> - Инициализация по умолчанию: <https://cppreference.com/cpp/language/default_initialization>
>
> **Стандарт:**
> - Инициализация по умолчанию: <https://eel.is/c++draft/dcl.init.general>
> - Пустая инициализация и время жизни объекта: <https://eel.is/c++draft/basic.life>

Инициализация по умолчанию — это инициализация, выполняемая при создании объекта без инициализатора.

```
T объект ;   (1)
new T        (2)
```

Инициализация по умолчанию выполняется в трёх ситуациях:

1. когда переменная с автоматической, статической длительностью хранения объявлена без инициализатора: `int a;`
2. когда объект с динамической продолжительностью хранения создаётся с помощью выражения new-expression без инициализатора: `int* ptr = new int;`
3. когда базовый класс или нестатический член данных не упомянут в списке инициализатора конструктора и этот конструктор вызывается (будет рассмотрено в ООП в теме «Конструкторы»).

Третий случай требует знания классов, поэтому разобран отдельно — см. 1.2.8.6 «Инициализация в конструкторе и способы инициализации int, double, string».

#### Инициализация по умолчанию: правила для разных категорий переменных

1. В локальной области скалярные переменные (арифметические типы) по умолчанию инициализированы, если они определены без выражения инициализации. Т.о. для встроенных типов (например, `int` и т.д.) переменная получает неопределённое значение.
   ```cpp
   int z; // неопределённое значение
   ```
   Чтение такой переменной — неопределённое поведение (см. [[lekciya-08#1.1.2.4 Объявление, инициализация, присваивание переменных|1.1.2.4 Объявление, инициализация, присваивание переменных]] и 1.6.3.4 «Неопределённое поведение (UB)»). Правило курса — инициализировать всегда: `int z{};`.
2. Массивы по умолчанию инициализированы при определении без выражения инициализации. Если массив инициализируется по умолчанию, его члены инициализируются по умолчанию и приобретают неопределённые значения.
   ```cpp
   int arr[3]; // неопределённое значение
   ```
3. Статические и глобальные переменные инициализируются один раз при запуске программы. Если не указано значение — инициализируются нулём (с неявным преобразованием к соответствующему типу).
   ```cpp
   static int int1;    // 0
   static char char1;  // '\0'
   static bool bool1;  // false
   std::string s1;     // ""
   int* globalPtr;     // для глобальной переменной = nullptr
   ```
4. Для объектов классов вызывается конструктор по умолчанию (если он есть). Если конструктора по умолчанию нет, возникнет ошибка компиляции.

### 1.3.1 Формальные и фактические параметры. Параметры со значениями по умолчанию

#### Формальные и фактические параметры

У слова «параметр» в разговоре о функциях два разных смысла: переменная, которую функция объявляет у себя, и значение, которое ей передают при вызове. Стандарт C++ различает их терминами *parameter* и *argument*.

> [!abstract] Формальный параметр (parameter)
> переменная, объявленная в списке параметров функции; получает значение при каждом вызове функции.

> [!abstract] Фактический параметр, аргумент (argument)
> выражение в круглых скобках вызова функции; его значение передаётся соответствующему формальному параметру.

> [!example] Пример 1.52 — Аргументы и параметры одного вызова
> ```cpp
> #include <iostream>
>
> double area(double width, double length)
> {
>     return width * length;
> }
>
> int main()
> {
>     double side = 1.5;
>     double roomLength = 4.0;
>     std::cout << area(2 * side, roomLength) << '\n'; // 12
> }
> ```
>
> Формальные параметры функции `area` — `width` и `length`. Аргументы вызова — выражения `2 * side` и `roomLength`. Аргументом может быть любое выражение подходящего типа, а не только имя переменной: сначала вычисляется значение `2 * side`, равное `3.0`, и уже оно передаётся параметру `width`.

#### Как аргумент попадает в параметр

Аргументы сопоставляются с параметрами **по позиции**: первый аргумент — первому параметру, второй — второму. Имена при этом роли не играют: переменная в вызове может называться иначе, чем параметр, или вовсе не быть переменной.

При вызове каждый параметр **инициализируется** значением своего аргумента — это именно инициализация, а не присваивание (различие этих понятий — в [[lekciya-08#1.1.2.4 Объявление, инициализация, присваивание переменных|1.1.2.4 Объявление, инициализация, присваивание переменных]]). Число аргументов должно совпадать с числом параметров; исключение — параметры со значениями по умолчанию, о которых ниже.

Если тип аргумента отличается от типа параметра, компилятор выполняет **неявное преобразование** типа; ошибка компиляции возникает, только когда такого преобразования нет. Например, аргумент типа `int` для параметра типа `double` преобразуется без потерь.

> [!warning] Ловушка: сужение типа при вызове
> Преобразование может и терять информацию: при передаче `double` в параметр типа `int` дробная часть молча отбрасывается.

#### Имена параметров в объявлении и определении

В объявлении функции (прототипе) имена параметров можно опускать — компилятору для проверки вызова достаточно типов:

```cpp
double area(double, double);                 // объявление без имён
double area(double width, double length);    // объявление с именами
```

Имена в объявлении и в определении одной функции могут различаться; совпадать должны типы параметров и их порядок. На практике имена в объявлении всё же пишут: они документируют, какой аргумент чему соответствует, — по прототипу `area(double width, double length)` сразу видно, где ширина, а где длина.

#### Параметры — локальные переменные функции

Формальные параметры, как и переменные, объявленные в теле функции, — **локальные**: они видны только внутри функции и создаются заново при каждом её вызове. Поэтому значения параметров одного вызова никак не связаны с другим вызовом той же функции. Где в памяти размещаются параметры и что происходит при вызове — в 1.3.5 «Рекурсивные функции»; как изменение параметра влияет (или не влияет) на аргумент — в 1.3.3 «Способы передачи параметров в функцию».

#### Параметры со значениями по умолчанию

Чтобы упростить вызов функции, в её объявлении можно указать значения параметров по умолчанию. Если при вызове соответствующий аргумент опущен, параметр инициализируется этим значением.

> [!abstract] Значение параметра по умолчанию (default argument)
> выражение, указанное в объявлении функции после имени параметра и знака `=`; используется для инициализации параметра, если при вызове соответствующий аргумент опущен.

> }
>
> int main()
> {
>     printBox(5);            // *****
>     printBox(5, '#');       // #####
>     printBox(5, '#', 2);    // две строки #####
> }
> ```

Правила задания значений по умолчанию:

1. **Значения задаются с конца списка.** Если у параметра есть значение по умолчанию, оно должно быть и у всех параметров после него. Соответственно, при вызове опускать можно только последние аргументы: если опущен один аргумент, опускаются и все, стоящие за ним.
2. **Значение указывается один раз** — обычно в объявлении функции, которое видят все вызывающие (в многофайловом проекте — в заголовочном файле, тема 1.5). Повторить его в определении нельзя, даже то же самое.
3. **Значением может быть любое выражение подходящего типа** — литерал, константа, вызов функции, — кроме обращения к другим параметрам той же функции и к локальным переменным. Выражение вычисляется заново при каждом вызове, в котором аргумент опущен.

#### Три способа передачи

В C++ аргумент можно передать функции тремя способами — по значению, по ссылке и по указателю. Сравним их на одной задаче — обмене значений двух переменных.

>     int temp = a;
>     a = b;
>     b = temp;
> }
>

> {
>     int temp = a;
>     a = b;
>     b = temp;

>     int temp = *a;
>     *a = *b;
>     *b = temp;
> }
>
> int main()
> {
>     int x = 1;
>     int y = 2;
>     swapByValue(x, y);
